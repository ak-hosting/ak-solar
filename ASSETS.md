# Asset durumu

Canlı sayfa yalnızca yerel CSS, JavaScript ve favicon kullanır. Solar görselleştirme CSS ile üretilir; harici fotoğraf, font, ikon, CDN veya analiz isteği yoktur.

`assets/images/` altındaki eski JPG/SVG dosyaları canlı `index.html` tarafından çağrılmaz. Yeniden kullanılmadan önce kaynak ve lisansları doğrulanmalıdır.
