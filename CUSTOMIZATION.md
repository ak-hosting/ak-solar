# Özelleştirme

1. `index.html` içindeki marka, hizmet ve süreç metinlerini doğrulanmış bilgilerle değiştirin.
2. `assets/css/style.css` başındaki renkleri ve düzeni markanıza uyarlayın.
3. `assets/js/script.js` içindeki temsili hesap modelini yetkili mühendislik verileriyle yeniden kurun.
4. Gerçek fiyat, üretim, geri ödeme, garanti veya teşvik iddiasını kaynak ve tarih olmadan yayınlamayın.
5. `npm test`, `npm run lint` ve `npm run build` komutlarını çalıştırıp mobil/masaüstü görünümü kontrol edin.
